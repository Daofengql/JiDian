# UI 与回归验证

验证环境：Windows、Chromium/Edge、Android Pixel 10 Pro XL 模拟器（实际 WebView），以及 ADB 连接的小米 M2102K1C 实机（Android 14，WebView 153）。

本文的 `artifacts/` 路径指本机验证产物。该目录包含设备截图、采样与分析材料，已由 `.gitignore` 排除，不随公开源码发布。

## 视觉检查与边界

检查了全屏地图、选点卡、悬浮面板展开／收起、速度区、权限弹窗、定点／步频／路线设置、实时状态、深色和横屏界面。横屏面板置于右侧，选点卡保留在左侧；展开面板后重新调整可见地图范围，选点和路线不会被面板遮挡。未发现水平溢出、主操作裁切或弹窗无法关闭。

探索场景包括无效坐标、高精度负数坐标、瓦片断网、模式切换后恢复、清空后撤销、速度为零、重复点、重复点击当前分段和运行中调整参数。

实机已覆盖 Root 自动配置、安装更新、现有位置／路线／参数保留、系统悬浮小地图和原生 GPS／Network 定位。测试期间恢复了临时加入的路线点和坐标。没有进行长时间厂商后台保活测试，也未覆盖所有历史 Android／WebView。基站与传感器目前为计算数据；Root 定位带系统 mock 标志。

## Hook 与地点导入增量验证

- 小米 Android 14、LSPosed 1.9.2：启用 JiDian 并只改动本模块作用域。默认 Hook 不调用 SU；显式切 Root 后自动配置并启动 GPS／Network TestProvider，停止后切回 Hook。
- 独立验证应用：Android 最近位置、当前位置和监听回调接收实时定点；定点更改后更新；停止或取消目标后恢复原始最近位置，不再继续产生模拟监听帧。伪造学习通包名访问快照被拒绝。
- 百度 API 测试替身：GCJ-02、WGS-84、BD-09LL 回调，停止 SDK 后不再发回调。真实学习通进程加载百度适配并连接快照桥，但登录后的签到定位页面尚未验证。
- 修复 Android 包可见性：只为选择的目标授予 `/snapshot` URI 访问；取消选择立即撤销。无需给学习通修改 Manifest。
- 输入坐标 → 导入地点：通过真实控件验证坐标系必选、多地点选择、定点导入、路线追加、只有活动 ID 时禁止导入。320 宽压缩弹窗间距后，坐标系与确认按钮同时可见；地址和详情用文本节点显示。
- Android ACTION_SEND 打开预览，不自动修改位置；系统 Geocoder 地址查询得到候选坐标。查找有 12 秒超时，改写文本或关闭弹窗会拒绝过期结果。
- 运行中的后端切换被禁用，目标选择支持点击整行；保存和取消均验证。
- 最终 Debug 安装实机复核：Hook 路线向独立应用报告 60 km/h 与连续经纬度；摇杆移动后松手保持同一坐标。Hook 前台服务使用 `specialUse`（类型 `0x40000000`），系统普通悬浮权限页面授权后显示 248 dp 小地图，见 `artifacts/hook-overlay-final-preview.png`。
- 验证应用已卸载，应用内目标恢复为仅学习通；测试路线清空，坐标、速度、抖动、海拔、步频与原始配置逐项相同，见 `artifacts/hook-final-restore.json`。模拟服务与系统 TestProvider 覆盖均已停止。
- 浏览器截图：`artifacts/import-preview-final-320.png`、`artifacts/import-preview-411.png`、`artifacts/hook-runtime-411.png`、`artifacts/hook-picker-320.png`；实机结果位于 `artifacts/hook-probe-*.json`。

学习通静态分析的证据与限制见 `CHAOXING-ANALYSIS.md`。没有执行签到，没有验证服务端返回地址的专用格式。Google LocationResult 分支已编译，但未在真实 Google Fused 服务端到端验证。当前模拟器在增量测试期间断开，Hook 无框架状态通过界面与启动路径检查，未重启用户模拟器。
